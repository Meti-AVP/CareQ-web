# CarQ Web — داشبورد الأدمن + بوابة المعارض

الواجهتين الويب بتوع **CarQ / سوقها**، مبنيين على **نفس نظام التصميم بتاع تطبيق
الموبايل بالحرف** — نفس الألوان، ونفس الخط، ونفس الخطوط المرسومة، ونفس نمط
«الرأس الملوّن + الشيت الأبيض».

| التطبيق | لمين | المنفذ |
|---|---|---|
| `apps/admin` | مالك CarQ — القرارات اللي بتحرّك فلوس | 3100 |
| `apps/dealers` | المعارض المتعاقدة — المخزون والمزايدة | 3200 |

**المواصفات المرجعية:** `docs/ADMIN_DASHBOARD_SPEC.md` و `docs/EXHIBITION_PORTAL_SPEC.md`.
أي سلوك في الكود بيشاور على قاعدة (`A-1`, `SN-2`, `F-6` …)، القاعدة هي المرجع.

---

## التشغيل

```bash
npm install          # مرة واحدة من جذر الـmonorepo
npm run dev:admin    # http://localhost:3100
npm run dev:dealers  # http://localhost:3200
```

**الدخول في وضع الديمو:** أي رقم موبايل + أي كود من ٤ أرقام.

البناء والفحص:

```bash
npm run build            # التطبيقين
npm run build:admin
npm run typecheck
```

> على ويندوز بذاكرة محدودة: `NODE_OPTIONS=--max-old-space-size=4096` قبل الأمر.

## الحالة: شغال بالكامل على موك — جاهز للربط

**مفيش باك اند لسه.** كل الشاشات مبنية على العقود النهائية وبتقرا من طبقة
موك واحدة، فالتبديل للباك اند الحقيقي **مش إعادة كتابة**:

```bash
# كل اللي مطلوب:
echo "NEXT_PUBLIC_API_URL=https://api.carq.eg" > apps/admin/.env.local
npx openapi-typescript https://api.carq.eg/openapi.json -o packages/api-client/src/schema.d.ts
```

`packages/api-client/src/client.ts` فيه `USE_MOCK` — بيتحوّل لـ`false` لوحده
أول ما يلاقي عنوان API. **ولا شاشة واحدة بتتغير.**

بيانات الموك مصمّمة عشان تعرض **الحالات الصعبة** اللي المواصفة بتحذّر منها،
مش الحالة المثالية: إعلانات `draft` محبوسة، إعلانات مش متسعّرة، طلبات
متأخرة عن الـSLA، مزادات متأخرة عن القفل، ومعارض مش متعاقدة.

## الهوية — منقولة من تطبيق الموبايل

| | القيمة |
|---|---|
| الحبر الكحلي | `#131A2E` |
| البرتقالي | `#EE4B1E` |
| الخلفية | `#F2F3F7` |
| الخط | Tajawal (400/500/700/800) |
| نصف القطر | 10 · 14 · 18 · 24 · 30 |

**الخطوط المرسومة (`StrokeMotif`)** منقولة بمساراتها وأطوالها المحسوبة من
`src/components/motion/StrokeMotif.tsx` في الموبايل — نفس الأشكال الخمسة
(circle · oval · underline · swoosh · ribbon) بنفس منحنى الرسم. ده اللي
بيخلي الويب والتطبيق يبانوا حاجة واحدة مش «مستوحى من».

**RTL:** الويب بيستخدم `<html dir="rtl">` الأصلية والمتصفح بيعكس لوحده.
**ممنوع `row-reverse` يدوي** — دي قاعدة React Native، مالهاش لازمة هنا.

**ممنوع إيموجي** في أي واجهة — قرار هوية متوارث من التطبيق.

## قواعد الرسوم البيانية

الباليتة **متحقق منها بسكريبت** على الخلفية الفاتحة والغامقة (نطاق الإضاءة،
أرضية التشبّع، فصل عمى الألوان، التباين). **متغيّرش لون بالحس.**

- **فئوية:** ٧ ألوان بترتيب ثابت، والرمادي = «أخرى» (وعاء مش سلسلة)
- **لما الألوان بتتقارن مباشرة** (دونات، شرايح مكدّسة): النواة الرباعية بس
- **متباعدة:** تيل ← رمادي محايد → برتقالي — لأي بيانات ليها اتجاهين حوالين صفر
- **ألوان الحالة محجوزة** للشارات والبلاطات، وعمرها ما تدخل رسم فئوي، ودايمًا مع أيقونة ونص
- **ممنوع dual-axis نهائيًا** — مقياسين مختلفين = رسمين
- كل رسم ليه **tooltip** و**«عرض كجدول»** و**تصدير CSV** — مفروضين في `ChartFrame`
- **سلسلة واحدة ⇒ من غير legend** (العنوان بيسمّيها)
- الحالة الفاضية مش رسم فاضي: «مفيش بيانات في الفترة دي»

## الأمان — مش قابل للتفاوض

1. **صور البطاقة وأوراق المعارض مفاتيح تخزين، مش روابط.** ممنوع تحطها في
   `<img src>` أو تبني رابط بإيدك. بتتعرض برابط **موقّع ٥ دقايق**، وكل فتحة
   بتتسجّل، وممنوع كاش أو تنزيل. قانون حماية البيانات المصري **١٥١/٢٠٢٠** بينطبق.
2. **أرقام التليفونات مخفية جزئيًا** افتراضيًا، وبتتكشف بضغطة واعية متسجّلة.
3. **التوكن في الذاكرة** — مش `localStorage`. لوحة فيها بيانات شخصية وأي XSS
   بيقرا `localStorage`.
4. **كل أكشن كتابة بيسيب صف تدقيق.** والأكشنات الخطرة (التعاقد · ترقية الدور ·
   الإيقاف · المزاد المتعثر · شارات الثقة) محتاجة **تأكيد مزدوج + سبب مكتوب**.
5. **مفيش حذف.** كل حاجة soft delete، وسجل التدقيق append-only.

## المتبقي على الباك اند

الشاشات مبنية على عقود مقترحة لـendpoints **لسه مش موجودة**. القايمة الكاملة
في `docs/ADMIN_DASHBOARD_SPEC.md §6.2` و `docs/EXHIBITION_PORTAL_SPEC.md §8.2`.
أهمها:

- `GET /v1/admin/stats/*` — كل التشارتس متوقفة عليها
- `POST /v1/admin/exhibitions` — **مفيش endpoint بينشئ معرض أصلًا**
- `PATCH /v1/admin/users/{id}/role` — الشرط ١ من ٣ للمزايدة
- `GET .../id-image` — الرابط الموقّع لصور البطاقة
- `POST /v1/exhibitions/applications` وطلبات الترقية كلها
- تضمين ملخص الإعلان في `GET /v1/auctions` و`GET /admin/sell-now/requests`
  (غير كده الجداول بتعمل N+1)
