# CarQ Admin — مواصفات داشبورد الأدمن (ويب)

> **لمين الملف ده:** فريق الفرونت اللي هيبني داشبورد الأدمن كـ**موقع ويب منفصل**
> (مش جوه تطبيق الموبايل). الملف ده بديل الشات: فيه كل شاشة، كل رسم بياني،
> ومصدر كل رقم من الداتابيز بالظبط.
>
> **اقرا الأول:**
> - `docs/BUSINESS_RULES.md` — قواعد العمل بأرقامها (`SN-2`, `A-1`, `F-6` …).
>   أي سلوك هنا بيشاور على قاعدة، القاعدة هي المرجع.
> - `docs/BACKEND_API.md` — سطح الـAPI العام.
> - `backend/app/models/` — الـschema الحقيقي (مصدر الحقيقة للأعمدة).
>
> **قاعدة ذهبية:** لو رسم بياني محتاج عمود مش موجود في قسم ٦، **قوله لنا**
> قبل ما تخترع حساب في الفرونت. الحسابات الخاطئة بتتحوّل قرارات فلوس غلط.

## ٠. ليه الداشبورد دي مش رفاهية

دلوقتي `backend/app/routers/admin.py` فيه **٨ endpoints شغالة ومتغطية بتستات،
ومحدش بينادي ولا واحد فيهم**. النتيجة إن **٣ فيتشرز أساسية واقفة تمامًا**:

| الفيتشر | الواقف فين | الأثر على المستخدم |
|---|---|---|
| **بيع حالًا** فوق ١٫٥ مليون ج.م | `SellNowRequest.status = pending` بينتظر قرار بشري (`SN-2`, قرار `D-4`) | البائع بيشوف «قيد المراجعة» وعمره ما هيوصله عرض |
| **مزاد المعارض** | `exhibitions.is_contracted` بيفضل `false` للأبد | **مفيش معرض واحد يقدر يزايد** — الفيتشر المدفوع الوحيد ميت (`A-1`) |
| **شارات الثقة** | `listings.km_verified` و `listings.inspected` | «ممشى موثّق» و«مفحوص» — أهم إشارتين ثقة — مستحيل تتمنح (`T-1`, `T-2`) |

الداشبورد دي هي الواجهة الوحيدة الممكنة للحاجات دي. من غيرها الباك اند شغال
في الفاضي.

## ١. الستاك

| الطبقة | الاختيار | ليه |

## ٢. الدخول والصلاحيات

**مفيش صفحة إنشاء حساب أدمن. خالص.** الدور `admin` بيتحط يدوي في الداتابيز
(`users.role`) وبس — ده مقصود (`BUSINESS_RULES §1`).

### فلو الدخول
نفس فلو الموبايل بالظبط، من غير أي اختراع:

```
POST /v1/auth/otp/request   { phone }                → 204
POST /v1/auth/otp/verify    { phone, code }          → { access_token, refresh_token, user }
GET  /v1/me                                          → { id, name, phone, role, ... }
   ↳ لو user.role !== 'admin'  →  اطلع بره فورًا، امسح التوكن، واعرض
     «الحساب ده مش مصرّح له» — من غير ما تقول إن فيه داشبورد أصلًا.
```

### إدارة التوكن
- `access_token` عمره **١٥ دقيقة**، و`refresh_token` **٣٠ يوم** وبيتدوّر مع كل
  استخدام (`I-4`).
- **متحطش التوكن في `localStorage`.** لوحة فيها أرقام تليفونات وصور بطاقات
  لازم تكون `httpOnly` cookie من Next route handler، أو in-memory + silent
  refresh. ده مش تفصيلة — ده XSS مباشر على بيانات شخصية.
- عند `401`: جدّد مرة واحدة وأعد المحاولة، وبعدها اطلع (نفس منطق
  `src/api/client.ts` في الموبايل — اقراه كمرجع).
- **الدور بيتقرا من الداتابيز مع كل request في الباك** (`require_role` في
  `core/deps.py`) — يعني سحب الصلاحية بيشتغل فورًا. متكاشيش الدور أكتر من
  دقيقة في الفرونت.

### عقد الأخطاء (X-4)
كل خطأ متوقع بيرجع بالشكل ده — **الرسالة بالعربي وجاهزة للعرض زي ما هي**:

```json
{ "error": { "code": "NOT_CONTRACTED", "message": "معرضك مش متعاقد مع CarQ", "fields": null } }
```

متكتبش رسايل خطأ من عندك. اعرض `error.message`، واستخدم `error.code` للمنطق.
الأكواد الثابتة اللي هتقابلك: `NOT_AUTHENTICATED` `FORBIDDEN` `NOT_FOUND`
`VALIDATION_ERROR` `CONFLICT` `RATE_LIMITED` — بالإضافة لأكواد الدومين
(`LISTING_NOT_FOUND`, `AUCTION_NOT_SETTLED`, `ENTRY_NOT_PAID` …).

## ٤. الشاشات بالتفصيل

### ٤٫١ `/` — نظرة عامة

**صف الـKPIs (٨ بلاطات).** كل بلاطة: رقم كبير + دلتا مقارنة بالفترة اللي
قبلها + خط sparkline صغير.

| البلاطة | المصدر |
|---|---|
| إعلانات نشطة | `count(listings where status='active')` |
| إعلانات جديدة (٧ أيام) | `count(listings where published_at >= now()-7d)` |
| **إعلانات محبوسة `draft`** | `count(listings where status='draft')` — **ده مؤشر إنذار، مش رقم عادي** (اقرا تحت) |
| مستخدمين جدد (٧ أيام) | `count(users where created_at >= now()-7d)` |
| طلبات بيع حالًا مفتوحة | `count(sell_now_requests where status in ('pending','offered'))` |
| **مستنية قرارك** | `count(... where status='pending')` — **لو > 0 لازم تبقى حمرا** |
| مزادات شغالة | `count(auctions where status='live')` |
| طلبات تمويل جديدة | `count(financing_applications where status='submitted')` |

> **`draft` ليه مؤشر إنذار:** قرار `D-2` بيقول الإعلان بيتنشر كـ`draft` و**أول
> صورة هي اللي بتفعّله**. يعني عدّاد `draft` عالي = رفع الصور باظ (تخزين مش
> متظبط، أو الـworker واقف). الرقم ده بيكشف عطل بنية تحتية من غير ما حد يبلّغ.

**التشارتس:** `C-01` … `C-08` من كتالوج قسم ٥.

**الفلاتر:** صف واحد فوق كل التشارتس (مش فلتر لكل رسم): مدى التاريخ
(٧ / ٣٠ / ٩٠ يوم / مخصص) + المحافظة + الماركة. الفلتر بيتطبّق على الصفحة كلها.

### ٤٫٢ `/sell-now` — طابور «بيع حالًا» ★

**الشاشة الأهم في الداشبورد.** ده الطابور اللي فيه ناس مستنية قرار بشري
بفلوس حقيقية (`SN-2`).

#### فهم الفلو قبل ما تبني

```
البائع بيطلب  →  السيرفر بيحسب suggested_price = round(price × 0.91 / 1000) × 1000
                 (services/sell_now.py: OFFER_RATIO, rule SN-1)
                        │
          ┌─────────────┴──────────────┐
   price ≤ 1,500,000                price > 1,500,000
   (AUTO_OFFER_CEILING)                    │
          │                                │
    عرض تلقائي فورًا              status = 'pending'
    status = 'offered'            ← مستني الأونر في الداشبورد دي
```

الحالات الكاملة (`SellNowStatus`):
`pending → offered → accepted → collected` — وفروع `declined` / `expired` / `cancelled`.

**مهم جدًا (`SN-7`):** `accepted` معناها العربية **محجوزة** (`listings.status =
reserved`)، **مش متباعة**. `collected` هي اللي بتخليها `sold`. لو خلطت
الاتنين، عربية اتلغى استلامها هتفضل «متباعة» للأبد.

#### التبويبات
`مستنية قرارك (pending)` · `عروض قايمة (offered)` · `مقبولة (accepted)` ·
`تم الاستلام (collected)` · `مرفوضة/منتهية` · `الكل`

**التبويب الافتراضي = `pending`** ومعاه عداد أحمر في الـsidebar.

#### أعمدة الجدول
| العمود | المصدر | ملاحظة |
|---|---|---|
| العربية | `listings.title` + صورة مصغّرة | لينك لـ`/listings/[id]` |
| سعر الإعلان | `listings.price` | |
| **الاقتراح (٩١٪)** | `sell_now_requests.suggested_price` | **بارز** — ده الافتراضي |
| العرض المصدَّر | `offer_price` | فاضي في `pending` |
| البائع | `users.name` + `users.phone` | التليفون قابل للنسخ بضغطة |
| الحالة | `status` | badge بلون status (قسم ٧) |
| **مستني بقاله** | `now() - created_at` | **أكبر من ٢٤ ساعة = أحمر** |
| ينتهي في | `expires_at` | عداد تنازلي — صلاحية العرض ٢٤ ساعة (`SN-3`) |

#### الأكشن الرئيسي — إصدار عرض
ديالوج فيه:
1. صورة العربية ومواصفاتها وسعر الإعلان.
2. **الاقتراح محطوط مسبقًا في خانة السعر** — الأونر بيعدّله أو بيأكده.
3. الفرق عن الاقتراح بيتحسب لايف: `«أقل من الاقتراح بـ ٤٥٬٠٠٠ ج.م (−٣٫١٪)»`.
4. حدود التحقق: `10,000 ≤ price ≤ 100,000,000` (نفس `OfferIn` في الباك).
5. زرار **«ابعت العرض»**.

```http
POST /v1/admin/sell-now/requests/{request_id}/offer
{ "price": 1455000 }
→ { "status": "offered", "offer_price": 1455000 }
```

بعدها: `POST .../collected` لما العربية تتستلم فعلًا والفلوس تتحرك.

> ⚠️ **الطلب بيوصل البائع ازاي؟** حاليًا عن طريق إشعار داخل التطبيق بس.
> الـpush مش متركّب في تطبيق الموبايل أصلًا. يعني الأونر ممكن يصدر عرض
> والبائع مايعرفش غير لما يفتح التطبيق. **اكتب ده في الديالوج كتحذير** لحد ما
> الـpush يتوصّل.

#### التشارتس: `C-10` … `C-14`

### ٤٫٣ `/listings` — الإعلانات والمراجعة

الفرونت بتاع الموبايل بيشوف `active | sold` بس، لأن الباك بيـ«يسقّط» الحالات
عليهم (`L-5`). **الداشبورد لازم تشوف السبعة كاملين:**
`draft` `active` `reserved` `sold` `expired` `removed` `rejected`.

**الفلاتر:** الحالة · الماركة · المحافظة · مدى السعر · مدى السنة ·
`km_verified` · `inspected` · **«من غير صور»** · «مش متسعّر» (`market_avg IS NULL`).

**الأعمدة:** صورة · العنوان · الماركة/الموديل/السنة · السعر ·
`market_avg` · `price_tag` (badge) · العداد · المحافظة · البائع ·
المشاهدات (`views_count`) · عدد الصور · الحالة · تاريخ النشر · تاريخ الانتهاء.

#### صفحة `/listings/[id]` — أكشنات الثقة ★

```http
PATCH /v1/admin/listings/{listing_id}/flags
{ "km_verified": true, "inspected": false }
→ { "km_verified": true, "inspected": false }
```

**الاتنين دول ممنوعين من أي endpoint بيستخدمه البائع** (`T-1`, `T-2`, `X-10`).
ده المسار الوحيد.

**الـUI لازم يفرض التفكير، مش مجرد toggle:**
- `km_verified` = **CarQ قرت العداد من صورة**، مش البائع كتبه. اعرض صور
  الإعلان جنب المفتاح، ولو فيه `scan_jobs.result` للعربية دي اعرض القراءة
  والثقة منه.
- خانة سبب إجبارية قبل التفعيل → بتتسجل في `audit_log.payload`.
- كل تغيير بيتسجل تلقائي في `audit_log` (`listing.flags_changed`) — اعرض
  التاريخ تحت المفتاح مباشرة.

**ناقص في الباك (قسم ٦٫٢):** مفيش endpoint للمراجعة (`rejected`) ولا للحذف
الإداري (`removed`) — لازم يتبنوا.

### ٤٫٤ `/exhibitions` — المعارض والتعاقد ★

**المفتاح اللي بيحيي المزاد.**

المزايدة محتاجة **٣ شروط مستقلة** (`A-1`، متطبّقة في
`services/auctions.py::_authorize_bidder`):

| # | الشرط | العمود | مين بيظبطه |
|---|---|---|---|
| ١ | `users.role == 'exhibition'` | `users.role` | **ناقص endpoint — قسم ٦٫٢** |
| ٢ | `exhibitions.is_contracted == true` | `exhibitions.is_contracted` | ✅ موجود |
| ٣ | `auction_entries.paid_at IS NOT NULL` | `auction_entries.paid_at` | ✅ موجود |

**كل شرط بيفشل برسالة مختلفة** — اعرضهم كـ٣ علامات منفصلة في صف المعرض، مش
حالة واحدة:

```
الدور: exhibition ✓   |   متعاقد: ✗   |   مدفوع للمزاد الحالي: —
   ↳ error code لو حاول يزايد: NOT_CONTRACTED
```

**الأعمدة:** الاسم · المحافظة/المنطقة · `verified` · **`is_contracted`
(مفتاح)** · عدد الإعلانات · عدد المزايدات · عدد المكاسب · آخر نشاط.

```http
PATCH /v1/admin/exhibitions/{exhibition_id}/contract
{ "is_contracted": true }
→ { "is_contracted": true }
```

ديالوج تأكيد: **«ده بيدي المعرض حق المزايدة بفلوس. متأكد؟»** — الأكشن ده
متسجّل في `audit_log` (`exhibition.contract_changed`, `X-8`).

> ⚠️ **فخ:** حاليًا **مفيش endpoint بينشئ معرض أصلًا** — لا للأدمن ولا لغيره.
> يعني `PATCH .../contract` بيشتغل بس على صفوف اتحطت بالإيد في الداتابيز.
> `POST /v1/admin/exhibitions` مطلوب — تفاصيله في `EXHIBITION_PORTAL_SPEC.md`.

### ٤٫٥ `/auctions` — المزادات

**الأعمدة:** العربية · المعرض البادئ · `start_price` (٨٥٪ من سعر الإعلان،
`A-2`) · `current_bid` · `reserve_price` · عدد المزايدات · `status` ·
`ends_at` (عداد حي) · `extension_count` (مرات التمديد المضاد للقنص، `A-5`).

**صفحة `/auctions/[id]`:**
- منحنى المزايدات على الوقت (`C-22`).
- جدول المزايدات: `auction_bids` + اسم المعرض (اسم المزايد **علني داخل
  المزاد بالتصميم** — `A-12`).
- جدول الـentries: أي معرض دافع وأي واحد لأ.
- زرار **«تعليم متعثر»** لما الفايز مايكملش (`A-11`):

```http
POST /v1/admin/auctions/{auction_id}/default     → { "status": "defaulted" }
POST /v1/admin/auction-entries/{entry_id}/paid   → { "paid_at": "..." }
```

`mark_defaulted` بيشتغل بس على مزاد `status='settled'` — غير كده بيرجع
`AUCTION_NOT_SETTLED`. اقفل الزرار في الحالات التانية بدل ما تسيب الخطأ يحصل.

> ⚠️ **لو الـworker مش شغال، المزادات مابتقفلش أبدًا** — هتفضل `live` وقت ما
> `ends_at` عدى. الداشبورد لازم تكشف ده صراحة: **«مزادات متأخرة عن القفل»**
> = `count(auctions where status='live' and ends_at < now())`. لو الرقم ده
> أكبر من صفر، فيه بانر أحمر في كل الصفحات (قسم ٤٫٨).

### ٤٫٦ `/financing` — طلبات التمويل

**الأعمدة:** مقدّم الطلب · العربية · الشريك (`partner_slug`، الافتراضي
`jameel`) · المقدم (`down_tier`) · المدة (`term_months`) · عادي/مرابحة
(`islamic`) · **القسط الشهري من `quote_snapshot`** · الحالة · تاريخ التقديم.

**`quote_snapshot` (JSONB) هو مصدر الحقيقة للأرقام** (`F-4`) — فيه النسبة
والمدة وأصل التمويل والقسط والإجمالي **وقت التقديم**. **متحسبش القسط من
النسب الحالية** — لو جميل غيّرت النسبة، الطلب القديم لازم يفضل بأرقامه.

**SLA معروض للمستخدم: تواصل خلال ٢٤ ساعة.** فالعمود «مستني بقاله» لازم
يتلوّن أحمر بعد ٢٤ ساعة، زي بيع حالًا.

#### 🔒 صور البطاقة — اقرا قسم ١٠ قبل ما تكتب سطر
`id_front_key` و `id_back_key` **مفاتيح تخزين، مش روابط**. ممنوع تحطهم في
`<img src>`. لازم endpoint بيولّد رابط موقّع ٥ دقايق ويسجّل كل فتحة (`F-6`).
الـendpoint ده **ناقص** — قسم ٦٫٢.

### ٤٫٧ `/users` — المستخدمين

**الأعمدة:** الاسم · التليفون · الدور (`individual` / `exhibition` / `admin`) ·
الحالة (`active` / `suspended` / `deleted`) · المحافظة · عدد الإعلانات ·
تاريخ التسجيل · آخر ظهور (`last_seen_at`).

**الأكشنات:** ترقية لـ`exhibition` · إيقاف · إلغاء إيقاف. **كلها ناقصة في
الباك** — قسم ٦٫٢.

**ترقية الدور = أخطر أكشن في الشاشة دي** (لأنها الشرط الأول من ٣ للمزايدة).
لازم تكون خطوتين + سبب + تسجيل تدقيق.

### ٤٫٨ `/health` — صحة النظام

الشاشة دي اتحطت هنا لسبب محدد: **الـworker مش منشور في الإنتاج حاليًا**
(اقرا التعليق فوق `render.yaml`). يعني ٨ جوبات مش بتشتغل. الشاشة دي بتخلي
العطل ده مرئي بدل ما يكون صامت.

| المؤشر | المصدر | الإنذار |
|---|---|---|
| مهام سكان في الطابور | `count(scan_jobs where status='queued')` | > 5 |
| **عمر أقدم مهمة queued** | `now() - min(created_at)` | **> ٥ دقايق = الـworker واقف** |
| مهام فشلت (٢٤ س) | `scan_jobs where status='failed'` | أي رقم |
| **مزادات متأخرة عن القفل** | `auctions where status='live' and ends_at < now()` | **> 0 = حرج** |
| عروض بيع حالًا منتهية ومش متقفلة | `sell_now_requests where status='offered' and expires_at < now()` | > 0 |
| إعلانات منتهية ولسه `active` | `listings where expires_at < now() and status='active'` | > 0 |
| إعلانات مش متسعّرة | `listings where status='active' and market_avg is null` | نسبة |
| مفاتيح idempotency قديمة | `idempotency_keys` | نمو مستمر |

**كل المؤشرات دي أعراض لسبب واحد: الـworker.** اعرضهم في كارت واحد عنوانه
«حالة العامل الخلفي» مع شرح الأثر لكل واحد.

### ٤٫٩ `/audit` — سجل التدقيق

```http
GET /v1/admin/audit?entity_type=listing&entity_id=<uuid>
→ [{ id, actorId, action, entityType, entityId, payload, createdAt }]
```

Timeline عمودي، فلترة بالكيان والفاعل والتاريخ. **السجل ده append-only

الأكشنات اللي بتتسجل حاليًا: `listing.flags_changed` ·

**قيد حالي:** الـendpoint `limit 200` من غير pagination ولا فلترة بالتاريخ —

### باليتة التشارتس — **متحقق منها بالسكريبت، متغيّرهاش بالحس**

اتولّدت واتفحصت بـ`dataviz/scripts/validate_palette.js` على الـsurface الفاتح
والغامق (٥ فحوص: نطاق الإضاءة، أرضية التشبّع، فصل عمى الألوان، أرضية الرؤية
العادية، التباين). **لو عايز تغيّر لون، شغّل السكريبت تاني قبل ما تدمج.**

**١. الفئوية (categorical) — بالترتيب ده بالظبط، وممنوع تدويرها:**

```
1  #EE4B1E   برتقالي CarQ
2  #3D6FD9   أزرق
3  #00998A   تيل
4  #A8791A   عسلي
5  #8E5BD0   بنفسجي
6  #D2426F   وردي
7  #4F7A28   زيتي
—  #6F7691   رمادي = «أخرى» (مش سلسلة، ده وعاء الباقي)
```

> نتيجة الفحص: **كل الفحوص PASS** في الفاتح والغامق (فحص الأزواج المتجاورة).
> **أسوأ زوج متجاور ΔE 8.9 (deutan) / 6.5 (tritan)** — يعني في نطاق الأرضية،
> فـ**إجباري** يبقى فيه ترميز تاني معاه: labels مباشرة، أو فواصل ٢px، أو texture.

**٢. لما أي لونين ممكن يتقارنوا مباشرة** (دونات، شرايح مكدّسة، legend طويل)
**استخدم النواة الرباعية بس** — دي اللي عدّت فحص **كل الأزواج** مش المتجاورة بس:

```
#EE4B1E   #3D6FD9   #00998A   #B5299B
```

**فوق ٤ فئات في دونات؟ متزوّدش لون — حوّل لشريط أفقي.** (البرتقالي والزيتي
مثلًا بيبقوا ΔE 1.1 لعمى الألوان البروتاني لو اتقارنوا جنب بعض — لون خامس في
دونات = رسم بيكدب على جزء من قرايته.)

**٣. المتدرّجة (sequential) — لون واحد فاتح←غامق** (للكثافة والخرايط):

```
#E3EAF9 → #C2D2F2 → #93B0E8 → #5E88DC → #3D6FD9 → #2B4E9C → #1D3466
```

**٤. المتباعدة (diverging) — للبيانات اللي ليها اتجاهين حوالين صفر**
(`C-13` العرض مقابل الاقتراح، `C-21` الارتفاع فوق البداية، والفرق عن
`market_avg`). **تيل ← رمادي محايد → برتقالي:**

```
#00998A ← #7FC4BD ← #E8E8EA → #F39A7E → #EE4B1E
```

النص **لازم** يكون رمادي محايد، **مش لون**. ده الشكل الطبيعي لمؤشر السعر
العادل: `deal` ناحية، `high` الناحية التانية، `fair` في النص.

**٥. ألوان الحالة — محجوزة، ممنوع تستخدمها كسلسلة رقم ٥:**

```
ناجح   #15803D
تحذير  #B45309
حرج    #B3261E
محايد  #6F7691
```

**قاعدة فصل:** ألوان الحالة عايشة في الـbadges والجداول وبلاطات الـKPI **بس** —
**عمرها ما تدخل رسم فيه ألوان فئوية**. وكل لون حالة بييجي **مع أيقونة ونص**،
عمره ما يبقى لون لوحده.

### مواصفات الرسم

- الأعمدة: **نهايات مدوّرة ٤px من ناحية القيمة بس**، ملزوقة في خط الأساس.
- الخطوط: **٢px**، النقط **≥ ٨px**.
- **فاصل ٢px بلون الـsurface** بين الشرايح المكدّسة وبين الأعمدة المتجاورة.
- الشبكة والمحاور **باهتة** (`--line`)، والقيم والـlabels **بألوان النص**
  (`--text` / `--text-sub`) — **عمرها ما تلبس لون السلسلة**.
- **سلسلة واحدة ⇒ من غير legend** (العنوان بيسمّيها). **٢ فأكتر ⇒ legend
  دايمًا**، ولحد ٤ كمان **labels مباشرة**.
- **متحطش رقم على كل نقطة** — علّم الأول والآخر والقمة وبس.
- **hover إجباري**: crosshair + tooltip للخط والمساحة، وtooltip لكل عنصر في
  الأعمدة والنقط. الاستثناء الوحيد: بلاطة رقم من غير رسم.
- **لكل رسم "عرض كجدول"** — إتاحة، ومصدر تصدير CSV في نفس الوقت.
- **الوضع الغامق يتظبط بإيدك** من نفس السلالم — **مش قلب تلقائي**.

### الحالات اللي لازم كل رسم يتعامل معاها
1. **مفيش داتا** (وده الوضع الافتراضي عند الإطلاق — قاعدة الإنتاج فاضية):
   «مفيش بيانات في الفترة دي» — **مش رسم فاضي ولا سبينر أبدي**.
2. **داتا قليلة** (< ٣ نقط): اعرض أرقام، مش خط.
3. **بيانات جزئية**: علّم النهارده كـ«لسه بيتجمع».
4. **قيم `null`**: `market_avg` و`price_tag` بيبقوا `null` لما مفيش مقارنات
   كفاية (`P-4`) — **شريحة «مش متسعّر» صريحة**، لا صفر ولا مخفية.

## ٨. RTL والصياغة

- `<html lang="ar" dir="rtl">` — سيب المتصفح يعكس التخطيط. متعملش
  `row-reverse` يدوي (دي قاعدة React Native، مالهاش لازمة هنا).
- **الرسوم البيانية استثناء:** المحور السيني في السلاسل الزمنية بيفضل
  **من الشمال لليمين** (الأقدم شمال) — ده المتعارف عليه عالميًا في التشارتس
  حتى في الواجهات العربية. **بس** المحور الصادي وأسماء الفئات بتتحاذي يمين.
- الأرقام **هندية غربية (0-9)** مع فواصل آلاف: `1,455,000 ج.م`.
  متستخدمش الأرقام العربية-الهندية في الجداول — بتكسر النسخ واللصق.
- التواريخ: `Africa/Cairo` دايمًا، بصيغة `١٢ سبتمبر ٢٠٢٦ · ٣:٤٥ م`.
  المدد النسبية: «من ساعتين»، «٣ أيام».
- **ممنوع إيموجي** في أي واجهة (قرار هوية من HANDOFF §٣).

## ١٠. الأمان والخصوصية — مش قابل للتفاوض

1. **صور البطاقة (`F-6`).** `id_front_key` / `id_back_key` **مفاتيح تخزين**.
   الباك بيرفض يطلّع رابط عام ليها (`is_private_key` في `storage/base.py`،
   والـmount بتاع `/media` بيرد `404` عليها). الفرونت:
   - **ممنوع** تحط المفتاح في `<img src>` أو تبني رابط بإيدك.
   - اطلب رابط موقّع (٥ دقايق) وقت العرض بس.
   - **متكاشيش الصورة ولا تنزّلها ولا تحطها في كانفاس.**
   - اعرض بانر فوق الصورة: «بيانات شخصية — كل فتحة متسجّلة».
   - قانون حماية البيانات المصري **١٥١/٢٠٢٠** بينطبق على الداتا دي.

2. **أرقام التليفونات.** مخفية جزئيًا افتراضيًا (`+20 100 ••• 553`)، وبتتكشف
   بضغطة واعية — والكشف بيتسجّل.

3. **محتوى الشات ماينفعش يتعرض بالكامل.** شاشة الشات في الداشبورد **مؤشرات
   وأرقام بس** (عدد الرسايل، زمن الرد). قراءة محادثة خاصة محتاجة سبب
   (بلاغ/نزاع) وتسجيل تدقيق — وده **مش في نطاق النسخة الأولى**.

4. **كل أكشن كتابة = صف تدقيق** (`X-8`). لو أكشن جديد مش بيتسجّل، ده باج
   في الباك — بلّغ عنه.

5. **تأكيد مزدوج** على: منح التعاقد، ترقية دور، إيقاف مستخدم، تعليم مزاد
   متعثر. ديالوج + سبب مكتوب.

6. **مفيش حذف.** كل حاجة soft delete (`X-6`). `audit_log` و`auction_bids`
   و`financing_applications` **ماتتمسحش أبدًا**.
